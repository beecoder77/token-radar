How the value is computed

Each protocol’s implied value comes from the snapshot itself, never from a hand-picked list of names. The market already prices token-bearing protocols: for every category we take the median market-cap / TVL ratio of the protocols in that category that have a token (at least 3 peers, otherwise the global median of 0.1689), and multiply the protocol’s TVL by it. That base is then adjusted for its 7-day TVL growth, for how long it has run with no token, and for how many chains it runs on. Categories that almost certainly never issue a token — exchanges, bridges, liquid-staking products — and versioned or wrapped names are discounted hard, so they sink instead of pretending to be farmable.

implied = TVL × category median (mcap/TVL) × growth × age × chains × discount

growth = 1 + clamp(7d change, −15%, +25%) ÷ 100  ·  age = 1 + min(years listed, 3) × 0.03  ·  chains = 1 + min(chains − 1, 4) × 0.02  ·  discount = 0.10 for CEX / Bridge / Liquid Staking & co, 0.25 for versioned or wrapped names, else 1.00

Data: the sealed 2026-11-14 DefiLlama snapshot (758 protocols at or above $5M TVL). Implied values are this radar’s own estimates from that snapshot — not predictions that a token will launch, or what it would be worth if it did. Nothing here is financial advice.
